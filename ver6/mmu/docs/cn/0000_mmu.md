## MMU 库：

MMU 库提供了 4 个 API，这些 API 目前还没有实际意义（不调用也不会影响其他API正常工作），主要是为了预留未来需求（多线程支持，或其他功能更新需要建立初始化数据时），提前提供的兼容性API（因此建议在编写代码时，添加对这些函数的调用）。

### MMU_Init
定义：int MMU_Init();
初始化 MMU 库，应该在进程初始化后，其他 MMU 库函数调用前调用此函数。
MMU 库初始化成功返回 TRUE，失败返回 FALSE。

### MMU_Unit
定义：void MMU_Unit();
卸载 MMU 库，应该在进程退出前，其他 MMU 库函数调用后调用此函数。

### MMU_Thread_Init
定义：int MMU_Thread_Init();
为当前线程初始化 MMU 库的运行数据，应该在线程创建时调用此函数。
MMU 库线程初始化成功返回 TRUE，失败返回 FALSE。

### MMU_Thread_Unit
定义：void MMU_Thread_Unit();
卸载当前线程的 MMU 库运行数据，应该在线程销毁时调用此函数。
