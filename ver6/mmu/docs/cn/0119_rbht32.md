## RBHT32（RBTree Hash Table 32）模块：

分类：实用性工具类（用于特定功能实现）

RBHT32 是基于 32位哈希算法 + RBTree 实现的哈希表，而不是使用传统哈希桶方式实现的。

二叉树具备非常强悍的查询性能，优秀的插入、删除性能，是制作哈希表的优秀选择，搭配 32 位哈希算法，节约单元数据的内存。

通常四种哈希表根据使用需要选择一种即可。

### RBHT32_Struct [数据结构]
``` c
typedef struct {
	RBTree_Struct RBT;
	#ifdef MMU_USE_MP256
		MP256_Object MP;
	#endif
} RBHT32_Struct, *RBHT32_Object;
```
RBHT32_Struct 是 RBHT32 对象的基本结构体数据，可以通过 RBHT32_Create 函数创建一个指向 RBHT32_Struct 结构体的指针（也就是 RBHT32_Object）。

RBHT32 必须使用已经初始化过的 RBHT32_Struct 数据结构（使用 RBHT32_Create），否则在进行 API 调用时，可能产生无法预知的严重后果。

### RBHT32_Object [对象指针]
RBHT32_Object 是 RBHT32_Struct 数据结构的指针，通过 RBHT32_Create 创建的 RBHT32 对象会返回 RBHT32_Object 对象指针。

### RBHT32_Create - 创建哈希表
声明：RBHT32_Object RBHT32_Create(unsigned int iItemLength);
创建 RBHT32 对象并初始化数据，创建成功时返回一个 RBHT32_Object 对象指针，创建失败返回 NULL。
由 RBHT32_Create 创建的对象，不再使用时应调用 RBHT32_Destroy 函数将 RBHT32 对象销毁，否则会产生内存泄漏。

### RBHT32_Destroy - 销毁哈希表
声明：void RBHT32_Destroy(RBHT32_Object objHT);
销毁由 RBHT32_Create 函数创建的 RBHT32 对象。

### RBHT32_Init - 初始化哈希表
声明：void RBHT32_Init(RBHT32_Object objHT, unsigned int iItemLength);
这个函数和 RBHT32_Create 功能类似，它在不申请 RBHT32 对象内存的情况下，对已存在的 RBHT32_Struct 数据进行初始化，将 RBHT32_Struct 嵌入到其他数据结构中的情况下，应使用此函数进行数据初始化。
嵌入到其他数据结构的 RBHT32_Struct 不再使用时应调用 RBHT32_Unit 函数释放对象中的数据，否则会产生内存泄漏。

### RBHT32_Unit - 释放哈希表
声明：void RBHT32_Unit(RBHT32_Object objHT);
释放 RBHT32 对象内的数据，它会将管理器成员数量清零，并释放管理器占用的内存。

### RBHT32_Set - 设置值
声明：void* RBHT32_Set(RBHT32_Object objHT, void* sKey, unsigned int iKeyLen);
设置表内 sKey 元素的值（sKey 的长度为 iKeyLen）。
运行后会返回 sKey 对应的元素结构体指针，可通过这个指针对 sKey 对应的元素进行操作。
如果表内不存在 sKey 对应的值，会创建新值返回。

### RBHT32_Get - 获取值
声明：void* RBHT32_Get(RBHT32_Object objHT, void* sKey, unsigned int iKeyLen);
获取表内 sKey 元素的值（sKey 的长度为 iKeyLen）。
运行后会返回 sKey 对应的元素结构体指针，可通过这个指针对 sKey 对应的元素进行操作。

### RBHT32_Remove - 删除值
声明：int RBHT32_Remove(RBHT32_Object objHT, void* sKey, unsigned int iKeyLen);
删除表内 sKey 元素的值（sKey 的长度为 iKeyLen）。
成功返回 TRUE，失败返回 FLASE（值不存在时）。

### RBHT32_Exists - 判断值是否存在
声明：int RBHT32_Exists(RBHT32_Object objHT, void* sKey, unsigned int iKeyLen);
判断表内 sKey 元素的值（sKey 的长度为 iKeyLen）是否存在。

### RBHT32_RemoveAll - 删除所有成员
RBHT32_Unit 的别名，为了避免歧义时，可以使用 RBHT32_RemoveAll。

### RBHT32_Clear - 清空管理器
RBHT32_Unit 的别名，为了避免歧义时，可以使用 RBHT32_Clear。

### RBHT32_Count - 获取表内元素数量
声明：unsigned int RBHT32_Count(RBHT32_Object objHT);
获取哈希表内元素的数量。

### RBHT32_Walk - 遍历表元素
声明：void RBHT32_Walk(RBHT32_Object objHT, HT32_EachProc procEach, void* pArg);
通过回调函数 recuProc 遍历哈希表所有元素，pArg 会作为 recuProc 的参数传递。
