## PAMM（Point Array Memory Management）模块

分类：内存管理器（主要用于管理内存的模块）

PAMM 模块用于管理指针数组，功能与 SAMM 类似（用于管理固定长度的结构体数组）。

PAMM 可以方便的管理一群指针，将指针添加到管理器、从管理器中删除指针、遍历管理器中的所有指针。

PAMM 是一种基于数组的内存管理器，因此具备数组的特性，拥有数组的优势和缺陷，优点包括：访问速度快，遍历元素容易，没有额外的结构占用内存等；缺点包括：插入删除性能低，数组内存地址在运行时会变化。

PAMM 的内存一定是连续的（数组特性），当元素所需的内存长度不足时，就会对内存进行扩容，当无法在原有地址进行数据扩容时，就会申请一块新的内存，并将原有的数据移动到新内存中，此时数据的地址将产生变化。

PAMM 在数组的基础上，提供了一些易用性功能，例如将数据插入到指定位置，或将指定位置的数据删除，或寻找数据空隙将数据填充进去。这些功能在特定情况下很有用，但由于数组的限制，这些功能的实现性能非常低，在不考虑性能的场合它们很好用，如果您的程序对性能敏感，则应该注意尽量不使用这些函数。

PAMM 主要的功能是内存管理，这意味着使用 PAMM 模块时，你不需要操心任何内存方面的问题，PAMM 会负责管理好内存，只需要正常的创建和销毁对象，就不会造成内存泄漏，对数组元素操作时，已申请的内存不足，PAMM 会自动对内存进行扩容，批量添加数据时，PAMM 使用的缓冲机制，也具备良好的性能表现。

PAMM 是一个偏底层的模块，它的功能有限但实用，许多其他模块都依赖 PAMM 进行内存管理，包括 MM256、动态栈（SDSTK、PDSTK）、LList 等。

### PAMM_Struct [数据结构]
``` c
typedef struct {
	void** Memory;							// 管理器内存指针
	unsigned int Count;						// 管理器中存在多少成员
	unsigned int AllocCount;				// 已经申请的结构数量
	unsigned int AllocStep;					// 预分配内存步长
} PAMM_Struct, *PAMM_Object;
```
PAMM_Struct 是 PAMM 对象的基本结构体数据，可以通过 PAMM_Create 函数创建一个指向 PAMM_Struct 结构体的指针（也就是 PAMM_Object），或将 PAMM_Struct 结构嵌入到您的数据中，使用 PAMM_Init 函数初始化 PAMM 数据。

PAMM 必须使用已经初始化过的 PAMM_Struct 数据结构（使用 PAMM_Create 或 PAMM_Init），否则在进行 API 调用时，可能产生无法预知的严重后果。

### PAMM_Object [对象指针]
PAMM_Object 是 PAMM_Struct 数据结构的指针，通过 PAMM_Create 创建的 PAMM 对象会返回 PAMM_Object 类型的对象指针。

### PAMM_Create - 创建指针内存管理器
声明：PAMM_Object PAMM_Create();
创建 PAMM 对象并初始化数据，创建成功时返回一个 PAMM_Object 对象指针，创建失败返回 NULL。
由 PAMM_Create 创建的对象，不再使用时应调用 PAMM_Destroy 函数将 PAMM 对象销毁，否则会产生内存泄漏。

### PAMM_Destroy - 销毁指针内存管理器
声明：void PAMM_Destroy(PAMM_Object pObject);
销毁由 PAMM_Create 函数创建的 PAMM 对象。

### PAMM_Init - 初始化内存管理器
声明：void PAMM_Init(PAMM_Object pObject);
这个函数和 PAMM_Create 功能类似，它在不申请 PAMM 对象内存的情况下，对已存在的 PAMM_Struct 数据进行初始化，将 PAMM_Struct 嵌入到其他数据结构中的情况下，应使用此函数进行数据初始化。
嵌入到其他数据结构的 PAMM_Struct 不再使用时应调用 PAMM_Unit 函数释放对象中的数据，否则会产生内存泄漏。

### PAMM_Unit - 释放内存管理器
声明：void PAMM_Unit(PAMM_Object pObject);
释放 PAMM 对象内的数据，它会将管理器成员数量清零，并释放管理器占用的内存。

### PAMM_Malloc - 分配内存
声明：int PAMM_Malloc(PAMM_Object pObject, unsigned int iCount);
PAMM_Malloc 是 PAMM 的内存分配函数，通常你不需要调用这个函数，因为 PAMM 会自己想办法管理内存，在适当的时候调用它，但如果你已经提前知道将要添加多少数据到 PAMM 中时，可以通过它来预先分配足够大的内存，来提升性能。
PAMM_Malloc 会将 PAMM 管理器的内存申请到能够容纳 iCount 个指针数据的状态，如果当前内存不足这个数量，会对内存进行扩容，如果当前内存超出了这个数量，则会对内存进行裁剪（如果管理器中的数据超过了这个数量，则会对数据进行裁剪）（例如 PAMM 中有 10 个数据，执行 PAMM_Malloc(obj, 5) 之后，PAMM 只会留下 5 个数据）。
操作成功返回 TRUE，操作失败返回 FALSE。

### PAMM_Insert - 插入成员
声明：unsigned int PAMM_Insert(PAMM_Object pObject, unsigned int iPos, void* pVal);
将一个指针插入到 PAMM 对象列表中，pVal 为要插入的指针，iPos 可以指定将指针插入到什么位置。
当 iPos 指定为 0 时，会将指针插入到数组最前面，当 iPos 指定为 PAMM.Count 时，会将指针插入到数组最后面，当 iPos 指定为某个元素的索引时（例如1），会将指针插入到这个索引的后面。
请注意，由于 PAMM 使用数组的方式管理内存，插入操作是非常低效的，在性能敏感的场合，应尽可能避免使用它。
操作成功返回位置序号（从1开始），操作失败返回 0。

### PAMM_Append - 添加成员
声明：unsigned int PAMM_Append(PAMM_Object pObject, void* pVal);
将一个指针添加到 PAMM 列表末尾，pVal 为要添加的指针地址。
这个函数非常高效，是操作 PAMM 指针数组时最建议采用的方式。
操作成功返回位置序号（从1开始），操作失败返回 0。

### PAMM_AddAlt - 添加成员，自动填充空隙
声明：unsigned int PAMM_AddAlt(PAMM_Object pObject, void* pVal);
将一个指针添加到 PAMM 列表，pVal 为要添加的指针地址。
PAMM_AddAlt 会先遍历数组元素，尝试寻找值为 NULL 的元素，将 pVal 写入到这里，如果找不到 NULL，则将 pVal 添加到列表末尾。
由于需要遍历数组，PAMM_AddAlt 性能较低（尤其是数组很长时），在性能敏感的场合，应尽可能避免使用它。
操作成功返回位置序号（从1开始），操作失败返回 0。

### PAMM_Swap - 交换成员
声明：int PAMM_Swap(PAMM_Object pObject, unsigned int iPosA, unsigned int iPosB);
交换两个成员的位置，相当于执行了 X = A; A = B; B = X; 的操作。
操作成功返回 TRUE，操作失败返回 FALSE。

### PAMM_Remove - 删除成员
声明：int PAMM_Remove(PAMM_Object pObject, unsigned int iPos, unsigned int iCount);
从第 iPos 个成员开始，删除 iCount 个数组元素。
请注意，由于 PAMM 使用数组的方式管理内存，删除操作是非常低效的，在性能敏感的场合，应尽可能避免使用它。
操作成功返回 TRUE，操作失败返回 FALSE。

### PAMM_RemoveAll - 删除所有成员
PAMM_Unit 的别名，为了避免歧义时，可以使用 PAMM_RemoveAll。

### PAMM_Clear - 清空成员
PAMM_Unit 的别名，为了避免歧义时，可以使用 PAMM_Clear。

### PAMM_GetVal - 获取成员值
声明：void* PAMM_GetVal(PAMM_Object pObject, unsigned int iPos);
获取第 iPos 个成员值的值（从1开始）。

### PAMM_GetVal_Unsafe - 获取成员值
声明：void* PAMM_GetVal_Unsafe(PAMM_Object pObject, unsigned int iPos);
功能和 PAMM_GetVal 相同，但不进行范围检查，如果 iPos 不在有效范围内，可能会返回错误的数据，或产生未知的后果。
在遍历 PAMM 列表元素时使用 PAMM_GetVal_Unsafe 可以提升性能。
或使用 PAMM_GetVal_Inline 内联函数获得更进一步的性能提升。

### PAMM_SetVal - 设置成员值
声明：int PAMM_SetVal(PAMM_Object pObject, unsigned int iPos, void* pVal);
设置第 iPos 个成员值的值（从1开始）为 pVal，这里 iPos 必须是已经存在的成员编号。
操作成功返回 TRUE，操作失败返回 FALSE。

### PAMM_SetVal_Unsafe - 设置成员值
声明：void PAMM_SetVal_Unsafe(PAMM_Object pObject, unsigned int iPos, void* pVal);
功能同 PAMM_SetVal，但不会进行范围安全检查，如果 iPos 不在有效范围内，可能产生未知的后果。

### PAMM_Sort - 数组排序
声明：int PAMM_Sort(PAMM_Object pObject, void* procComp);
对 PAMM 内所有成员进行排序，排序规则根据 procComp 回调函数决定。
procComp 函数声明：int procComp(void* v1, void* v2);
排序时 PAMM_Sort 函数会不断调用 procComp 对 v1 和 v2 进行比较，procComp 的返回值决定比较结果，返回负数则会将 v2 排在 v1 前面，返回正数则会将 v1 排在 v2 前面，返回 0 则两个元素的位置不变。
procComp 函数的参数类型可以根据需要设置，但必须是指针类型。
