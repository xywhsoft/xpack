## MM256（Memory Management 256）模块：

分类：内存管理器（主要用于管理内存的模块）

MM256 相当于可以分配固定大小内存块的内存池，它可以做到在稳定的时间周期内，非常高效的分配和释放内存。

MM256 通过 BSMM 管理很多个 MMU256 单元，并将他们归类到四个链表内（空闲单元、满载单元、全空单元、已释放单元），每次申请内存时，都会从空闲单元中直接分配，如果没有空闲单元，则会从全空单元或已释放单元中尝试复用，或创建全新的内存管理单元；这个流程中只有线性的代码被执行，所以 MM256 的效率非常高。

MM256 会自动管理内存，当已申请的内存管理单元不足以容纳将要申请的内存数量时，MM256 会自动扩容，当已使用的内存被释放时，MM256 会自动释放不再使用的管理器，但 MM256 总会后备一个空闲的管理器单元作为缓冲，避免在某个临界状态下反复内存申请和释放可能会产生性能问题的情况。

MM256 最多能管理 10 亿个内存数据（1,073,741,823个），超出这个数据数量，只需要少量改进就可以进行扩容。

MM256 非常擅长管理众多的小内存，例如为 表格结构、树结构、大量字符串、各种结构值 提供内存管理能力，能够极为可观的提升运行速度，避免内存碎片化。

作为交换，MM256 会产生一定的内存浪费，例如只申请了 1 个元素内存时，MM256 实际上创建了 256 个元素内存作为缓冲，当然在如今的计算机配置下，这样的浪费是值得的，尤其是当它能够大幅提升程序性能时，与其类似的另一个模块 MM64K 则更为极端，用更大的内存浪费，来换取更加激进的性能。

### MM256_Struct [数据结构]
``` c
// 内存管理器链表结构
typedef struct MMU256_LLNode {
	unsigned int Flag;
	MMU256_Object objMMU;
	struct MMU256_LLNode* Prev;
	struct MMU256_LLNode* Next;
} MMU256_LLNode;

// 256步进内存管理器数据结构
typedef struct {
	unsigned int ItemLength;					// 成员占用内存长度
	BSMM_Struct arrMMU;							// MMU 阵列
	MMU256_LLNode* LL_Idle;						// 空闲的 MMU 内存管理单元链表 (优先分配内存的单元)
	MMU256_LLNode* LL_Full;						// 满载的 MMU 内存管理单元链表 (不会从这些单元中分配内存)
	MMU256_LLNode* LL_Null;						// 全空的 MMU 内存管理单元 (备用单元，最多只留一个)
	MMU256_LLNode* LL_Free;						// 已释放的 MMU 内存管理单元链表 (申请新单元优先从这里找)
	MMU_OnErrorProc OnError;					// 错误处理回调函数
} MM256_Struct, *MM256_Object;
```
MM256_Struct 是 MM256 对象的基本结构体数据，可以通过 MM256_Create 函数创建一个指向 MM256_Struct 结构体的指针（也就是 MM256_Object）。

MM256 必须使用已经初始化过的 MM256_Struct 数据结构（使用 MM256_Create），否则在进行 API 调用时，可能产生无法预知的严重后果。

### MM256_Object [对象指针]
MM256_Object 是 MM256_Struct 数据结构的指针，通过 MM256_Create 创建的 MM256 对象会返回 MM256_Object 对象指针。

### MM256_Create - 创建内存管理器
声明：MM256_Object MM256_Create(unsigned int iItemLength);
创建 MM256 对象并初始化数据，创建成功时返回一个 MM256_Object 对象指针，创建失败返回 NULL。
参数 iItemLength 用于指定管理器内，结构体单元的数据长度，通常使用 sizeof 获取对应结构体的内存占用长度。
由 MM256_Create 创建的对象，不再使用时应调用 MM256_Destroy 函数将 MM256 对象销毁，否则会产生内存泄漏。

### MM256_Destroy - 销毁内存管理器
声明：void MM256_Destroy(MM256_Object objMM);
销毁由 MM256_Create 函数创建的 MM256 对象。

### MM256_Init - 初始化内存管理器
声明：void MM256_Init(MM256_Object objMM, unsigned int iItemLength);
这个函数和 MM256_Create 功能类似，它在不申请 MM256 对象内存的情况下，对已存在的 MM256_Struct 数据进行初始化，将 MM256_Struct 嵌入到其他数据结构中的情况下，应使用此函数进行数据初始化。
嵌入到其他数据结构的 MM256_Struct 不再使用时应调用 MM256_Unit 函数释放对象中的数据，否则会产生内存泄漏。

### MM256_Unit - 释放内存管理器
声明：void MM256_Unit(MM256_Object objMM);
释放 MM256 对象内的数据，它会将管理器成员数量清零，并释放管理器占用的内存。

### MM256_Alloc - 申请内存
声明：void* MM256_Alloc(MM256_Object objMM);
申请一块内存，内存长度为管理器创建时指定的长度，返回内存指针，失败返回 NULL。

### MM256_Free - 释放内存
声明：void MM256_Free(MM256_Object objMM, void* ptr);
释放内存（必须是由 MM256_Alloc 函数申请的，否则可能会导致未知的严重后果）。
一块内存不可以反复释放，否则会扰乱内存申请逻辑。

### MM256_GC_Mark - GC标记
声明：void MM256_GC_Mark(void* obj);
为一块内存添加标记，这个标记可以用于GC内存回收。

### MM256_GC - 执行GC回收内存
声明：void MM256_GC(MM256_Object objMM, int bFreeMark);
执行一轮GC回收，bFreeMark 参数指定了是回收被标记的内存(TRUE)，还是回收没有被标记的内存(FALSE)。
GC回收后，会重置内存的 GC 标记状态。
