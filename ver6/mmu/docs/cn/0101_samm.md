## SAMM（Struct Array Memory Management）模块：

分类：内存管理器（主要用于管理内存的模块）

SAMM 模块用于管理结构体数组，功能与 PAMM 和 BSMM 类似。

PAMM 专用于管理指针数据，SAMM 则可以管理任意长度的结构体数据，功能上 SAMM 能够实现 PAMM 的所有功能，但在专门管理指针数组时，不如 PAMM 方便。

BSMM 和 SAMM 在功能上是重合的，两者都用于管理结构体内存，区别在于 SAMM 是严格按照数组格式存储数据的（数据是连续的），而 BSMM 则按照多个区块的方式来管理数据（数据是零散的）；因此 SAMM 的数据按下标访问速度更快，适合写少读多的情况下使用，而 BSMM 的数据扩容速度更快，适合写入较多的情况下使用，同时 BSMM 返回的结构体地址不会变化。

SAMM 可以方便的管理一群结构体数据和内存，从管理器中添加一个结构体、将结构体从管理器中删除、遍历管理其中的所有结构体。

SAMM 是一种基于数组的内存管理器，因此具备数组的特性，拥有数组的优势和缺陷，优点包括：访问速度快，遍历元素容易，没有额外的结构占用内存等；缺点包括：插入删除性能低，数组内存地址在运行时会变化（这一点对SAMM尤其需要注意，请勿在外部保存 SAMM 的结构体指针用于后续的元素访问，一旦 SAMM 数据地址变化，将造成不可预估的影响）。

SAMM 在数组的基础上，提供了一些易用性功能，例如将数据插入到指定位置，或将指定位置的数据删除。这些功能在特定情况下很有用，但由于数组的限制，这些功能的实现性能非常低，在不考虑性能的场合它们很好用，如果您的程序对性能敏感，则应该注意尽量不使用这些函数。

SAMM 主要的功能是内存管理，这意味着使用 SAMM 模块时，你不需要操心任何内存方面的问题，SAMM 会负责管理好内存，只需要正常的创建和销毁对象，就不会造成内存泄漏，对数组元素操作时，已申请的内存不足，SAMM 会自动对内存进行扩容，批量添加数据时，SAMM 使用的缓冲机制，也具备良好的性能表现。

### SAMM_Struct [数据结构]
``` c
typedef struct {
	char* Memory;						// 管理器内存指针
	unsigned int ItemLength;			// 成员占用内存长度
	unsigned int Count;					// 管理器中存在多少成员
	unsigned int AllocCount;			// 已经申请的结构数量
	unsigned int AllocStep;				// 预分配内存步长
} SAMM_Struct, *SAMM_Object;
```
SAMM_Struct 是 SAMM 对象的基本结构体数据，可以通过 SAMM_Create 函数创建一个指向 SAMM_Struct 结构体的指针（也就是 SAMM_Object），或将 SAMM_Struct 结构嵌入到您的数据中，使用 SAMM_Init 函数初始化 SAMM 数据。

SAMM 必须使用已经初始化过的 SAMM_Struct 数据结构（使用 SAMM_Create 或 SAMM_Init），否则在进行 API 调用时，可能产生无法预知的严重后果。

### SAMM_Object [对象指针]
SAMM_Object 是 SAMM_Struct 数据结构的指针，通过 SAMM_Create 创建的 SAMM 对象会返回 SAMM_Object 类型的对象指针。

### SAMM_Create - 创建结构化内存管理器
声明：SAMM_Object SAMM_Create(unsigned int iItemLength);
创建 SAMM 对象并初始化数据，创建成功时返回一个 SAMM_Object 对象指针，创建失败返回 NULL。
参数 iItemLength 用于指定管理器内，结构体单元的数据长度，通常使用 sizeof 获取对应结构体的内存占用长度。
由 SAMM_Create 创建的对象，不再使用时应调用 SAMM_Destroy 函数将 SAMM 对象销毁，否则会产生内存泄漏。

### SAMM_Destroy - 销毁结构化内存管理器
声明：void SAMM_Destroy(SAMM_Object pObject);
销毁由 SAMM_Create 函数创建的 SAMM 对象。

### SAMM_Init - 初始化内存管理器
声明：void SAMM_Init(SAMM_Object pObject, unsigned int iItemLength);
这个函数和 SAMM_Create 功能类似，它在不申请 SAMM 对象内存的情况下，对已存在的 SAMM_Struct 数据进行初始化，将 SAMM_Struct 嵌入到其他数据结构中的情况下，应使用此函数进行数据初始化。
嵌入到其他数据结构的 SAMM_Struct 不再使用时应调用 SAMM_Unit 函数释放对象中的数据，否则会产生内存泄漏。

### SAMM_Unit - 释放内存管理器
声明：void SAMM_Unit(SAMM_Object pObject);
释放 SAMM 对象内的数据，它会将管理器成员数量清零，并释放管理器占用的内存。

### SAMM_Malloc - 分配内存
声明：int SAMM_Malloc(SAMM_Object pObject, unsigned int iCount);
SAMM_Malloc 是 SAMM 的内存分配函数，通常你不需要调用这个函数，因为 SAMM 会自己想办法管理内存，在适当的时候调用它，但如果你已经提前知道将要添加多少数据到 SAMM 中时，可以通过它来预先分配足够大的内存，来提升性能。
SAMM_Malloc 会将 SAMM 管理器的内存申请到能够容纳 iCount 个结构体数据的状态，如果当前内存不足这个数量，会对内存进行扩容，如果当前内存超出了这个数量，则会对内存进行裁剪（如果管理器中的数据超过了这个数量，则会对数据进行裁剪）（例如 SAMM 中有 10 个数据，执行 SAMM_Malloc(obj, 5) 之后，SAMM 只会留下 5 个数据）。
操作成功返回 TRUE，操作失败返回 FALSE。

### SAMM_Insert - 插入成员
声明：unsigned int SAMM_Insert(SAMM_Object pObject, unsigned int iPos, unsigned int iCount);
将 iCount 个结构体数据插入到 SAMM 对象列表中，iPos 可以指定将这些结构体插入到什么位置。
当 iPos 指定为 0 时，会将结构体插入到数组最前面，当 iPos 指定为 SAMM.Count 时，会将结构体插入到数组最后面，当 iPos 指定为某个元素的索引时（例如1），会将结构体插入到这个索引所属结构体的后面。
请注意，由于 SAMM 使用数组的方式管理内存，插入操作是非常低效的，在性能敏感的场合，应尽可能避免使用它。
操作成功返回首个结构体元素的位置序号（从1开始），操作失败返回 0。

### SAMM_Append - 添加成员
声明：unsigned int SAMM_Append(SAMM_Object pObject, unsigned int iCount);
将 iCount 个结构体数据添加到 SAMM 列表末尾。
这个函数非常高效，是操作 SAMM 指针数组时最建议采用的方式。
操作成功返回首个结构体元素的位置序号（从1开始），操作失败返回 0。

### SAMM_Swap - 交换成员
声明：int SAMM_Swap(SAMM_Object pObject, unsigned int iPosA, unsigned int iPosB);
交换两个成员的位置，相当于执行了 X = A; A = B; B = X; 的操作。
操作成功返回 TRUE，操作失败返回 FALSE。

### SAMM_Remove - 删除成员
声明：int SAMM_Remove(SAMM_Object pObject, unsigned int iPos, unsigned int iCount);
从第 iPos 个成员开始，删除 iCount 个数组元素。
请注意，由于 SAMM 使用数组的方式管理内存，删除操作是非常低效的，在性能敏感的场合，应尽可能避免使用它。
操作成功返回 TRUE，操作失败返回 FALSE。

### SAMM_RemoveAll - 删除所有成员
SAMM_Unit 的别名，为了避免歧义时，可以使用 SAMM_RemoveAll。

### SAMM_Clear - 清空成员
SAMM_Unit 的别名，为了避免歧义时，可以使用 SAMM_Clear。

### SAMM_GetPtr - 获取成员指针
声明：void* SAMM_GetPtr(SAMM_Object pObject, unsigned int iPos);
获取第 iPos 个结构体元素的指针（从1开始）。

### SAMM_GetPtr_Unsafe - 获取成员指针
声明：void* SAMM_GetPtr_Unsafe(SAMM_Object pObject, unsigned int iPos);
功能和 SAMM_GetPtr 相同，但不进行范围检查，如果 iPos 不在有效范围内，可能会返回错误的数据，或产生未知的后果。
在遍历 SAMM 列表元素时使用 SAMM_GetPtr_Unsafe 可以提升性能。
或使用 SAMM_GetPtr_Inline 内联函数获得更进一步的性能提升。

### SAMM_Sort - 数组排序
声明：int SAMM_Sort(SAMM_Object pObject, void* procCompar);
对 SAMM 内所有成员进行排序，排序规则根据 procComp 回调函数决定。
procComp 函数声明：int procComp(void* v1, void* v2);
排序时 SAMM_Sort 函数会不断调用 procComp 对 v1 和 v2 进行比较，procComp 的返回值决定比较结果，返回负数则会将 v2 排在 v1 前面，返回正数则会将 v1 排在 v2 前面，返回 0 则两个元素的位置不变。
procComp 函数的参数类型可以根据需要设置，但必须是指针类型。
