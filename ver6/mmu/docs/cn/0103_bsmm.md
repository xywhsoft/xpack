## BSMM（Blocks Struct Memory Management）模块：

分类：内存管理器（主要用于管理内存的模块）

BSMM 模块用于管理结构体数组，功能与 SAMM 类似。

BSMM 和 SAMM 在功能上是重合的，两者都用于管理结构体内存，区别在于 SAMM 是严格按照数组格式存储数据的（数据是连续的），而 BSMM 则按照多个区块的方式来管理数据（数据是零散的）；因此 SAMM 的数据按下标访问速度更快，适合写少读多的情况下使用，而 BSMM 的数据扩容速度更快，适合写入较多的情况下使用，同时 BSMM 返回的结构体地址不会变化。

BSMM 是一种按页管理结构体内存的模块，每 256 个结构体为一个页面，BSMM 会根据需要申请若干个页去容纳管理其中的结构体数据，当已申请的内存被占满时，会自动申请新的内存页面。

BSMM 是一个偏底层的模块，它主要用于管理其他更复杂的数据结构中的页面索引数据，多用于需要查询性能和写入性能要求均衡的场景下，为了保证这两个指标，BSMM 在释放结构体内存时，不仅不会真的释放内存，还会增加内存使用量（申请一小块内存保存已释放内存的链表数据，极端情况下，可能会导致内存碎片化严重），BSMM 也不会在运行的过程中主动削减页面数量。

因此，除非你知道 BSMM 的运行机制和这样设计的原因，以及它适合使用的场景，否则更建议采用 MM256 或 SAMM 替代 BSMM 的功能。

### BSMM_Struct [数据结构]
``` c
typedef struct {
	unsigned int ItemLength;			// 成员占用内存长度
	unsigned int Count;					// 管理器中存在多少成员
	PAMM_Struct PageMMU;				// 内存页管理器
	MemPtr_LLNode* LL_Free;				// 已释放的内存块链表
} BSMM_Struct, *BSMM_Object;
```
BSMM_Struct 是 BSMM 对象的基本结构体数据，可以通过 BSMM_Create 函数创建一个指向 BSMM_Struct 结构体的指针（也就是 BSMM_Object），或将 BSMM_Struct 结构嵌入到您的数据中，使用 BSMM_Init 函数初始化 BSMM 数据。

BSMM 必须使用已经初始化过的 BSMM_Struct 数据结构（使用 BSMM_Create 或 BSMM_Init），否则在进行 API 调用时，可能产生无法预知的严重后果。

### BSMM_Object [对象指针]
BSMM_Object 是 BSMM_Struct 数据结构的指针，通过 BSMM_Create 创建的 BSMM 对象会返回 BSMM_Object 对象指针。

### BSMM_Create - 创建数据块结构内存管理器
声明：BSMM_Object BSMM_Create(unsigned int iItemLength);
创建 BSMM 对象并初始化数据，创建成功时返回一个 BSMM_Object 对象指针，创建失败返回 NULL。
参数 iItemLength 用于指定管理器内，结构体单元的数据长度，通常使用 sizeof 获取对应结构体的内存占用长度。
由 BSMM_Create 创建的对象，不再使用时应调用 BSMM_Destroy 函数将 BSMM 对象销毁，否则会产生内存泄漏。

### BSMM_Destroy - 销毁数据块结构内存管理器
声明：void BSMM_Destroy(BSMM_Object objBSMM);
销毁由 BSMM_Create 函数创建的 BSMM 对象。

### BSMM_Init - 初始化数据块结构内存管理器
声明：void BSMM_Init(BSMM_Object objBSMM, unsigned int iItemLength);
这个函数和 BSMM_Create 功能类似，它在不申请 BSMM 对象内存的情况下，对已存在的 BSMM_Struct 数据进行初始化，将 BSMM_Struct 嵌入到其他数据结构中的情况下，应使用此函数进行数据初始化。
嵌入到其他数据结构的 BSMM_Struct 不再使用时应调用 BSMM_Unit 函数释放对象中的数据，否则会产生内存泄漏。

### BSMM_Unit - 释放数据块结构内存管理器
声明：void BSMM_Unit(BSMM_Object objBSMM);
释放 BSMM 对象内的数据，它会将管理器成员数量清零，并释放管理器占用的内存。

### BSMM_Alloc - 申请结构体内存
声明：void* BSMM_Alloc(BSMM_Object objBSMM);
申请一块结构体内存，结构体内存通过内部页面分配，将返回一个预设的结构体内存指针。

### BSMM_Free - 释放结构体内存
声明：void BSMM_Free(BSMM_Object objBSMM, void* Ptr);
释放一块结构体内存，注意这个函数不会真的释放对应结构体占据的内存，而是申请一块内存作为链表元素，将这块内存标记为可复用状态。

### BSMM_GetPtr_Inline - 获取成员指针
声明：void* BSMM_GetPtr_Inline(BSMM_Object objBSMM, unsigned int iIdx);
获取管理器内存中，指定顺序的结构体指针，这个顺序是从 0 开始的。
非特殊需求不建议使用这个函数，本质上 BSMM 是一个简单的内存分配器，它为更复杂的内存分配器最基础建设，这个函数违背了它作为一个内存分配器的设计理念，使其更像是一个数组。
