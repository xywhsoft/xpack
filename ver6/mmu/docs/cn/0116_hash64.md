## Hash64（rapidhash）模块：

分类：实用性工具类（用于特定功能实现）

rapidhash 是性能非常优秀的 64 位哈希算法，无论是 Hash 速度，还是碰撞特性都非常好，MMU 选择使用这种算法作为 Hash Table 的实现算法，你也可以单独使用这种算法进行哈希值计算。

rapidhash 基于 BSD2 协议开源，源代码中已附带开源许可证。

### Hash64_WithSeed - 计算 32 位哈希值
声明：unsigned long long Hash64_WithSeed(void* key, size_t len, unsigned long long seed);
计算 key 的哈希值，其中 key 的长度为 len。
使用 seed 作为随机种子。

### Hash64 - 计算 32 位哈希值
声明：unsigned long long Hash64(void* key, size_t len);
计算 key 的哈希值，其中 key 的长度为 len。

### Hash64Inline - 计算 32 位哈希值
声明：unsigned long long Hash64Inline(void* key, size_t len, unsigned long long seed);
计算 key 的哈希值，其中 key 的长度为 len。
使用 seed 作为随机种子。
Hash64Inline 为内联函数，会略微提升运行效率，但显著增加程序体积。
