## MBMU（Memory Buffer Management Unit）模块：

分类：实用性工具类（用于特定功能实现）

MBMU 内存缓冲区管理单元用于管理增量内存缓冲区，最常见的用途是作为 StringBuilder 使用，它支持 ANSI、UTF8、UTF16、UTF32、BINARY 等多种不同编码（实际上就是尾部添加截断字符的区别），它也可以用来生成二进制的数据，例如在内存中构建文件格式，再统一写入。

MBMU 可以作为一个内存辅助工具使用，将数据投喂给它，它会帮助你解决一切内存管理的问题，由于自增缓冲区机制的存在，使用 MBMU 进行字符串拼接操作可以获得极大的性能提升（解决了反复内存申请释放导致字符串拼接带来的性能下降问题）。

MBMU 针对字符串处理做了优化，在字符串模式下会自动添加数据末尾的 \0（ANSI、GBK、UTF-8） 或 \0\0（UTF-16） 或 \0\0\0\0（UTF-32），它也可以用于管理二进制数据，因为其内部使用单独的变量存储数据长度，而不是根据数据末尾的 \0 来判断数据长度。

### MBMU_Struct [数据结构]
``` c
typedef struct {
	char* Buffer;							// 内存缓冲区
	unsigned int Length;					// 内存长度
	unsigned int AllocLength;				// 已申请内存长度
	unsigned int AllocStep;					// 预分配内存步长
} MBMU_Struct, *MBMU_Object;
```
MBMU_Struct 是 MBMU 对象的基本结构体数据，可以通过 MBMU_Create 函数创建一个指向 MBMU_Struct 结构体的指针（也就是 MBMU_Object），或将 MBMU_Struct 结构嵌入到您的数据中，使用 MBMU_Init 函数初始化 MBMU 数据。

MBMU 必须使用已经初始化过的 MBMU_Struct 数据结构（使用 MBMU_Create 或 MBMU_Init），否则在进行 API 调用时，可能产生无法预知的严重后果。

### MBMU_Object [对象指针]
MBMU_Object 是 MBMU_Struct 数据结构的指针，通过 MBMU_Create 创建的 MBMU 对象会返回 MBMU_Object 类型的对象指针。

### MBMU_Create - 创建内存缓冲区管理器
声明：MBMU_Object MBMU_Create(unsigned int iAllocLength, unsigned int iStep);
创建 MBMU 对象并初始化数据，创建成功时返回一个 MBMU_Object 对象指针，创建失败返回 NULL。
参数 iAllocLength 用于指定管理器初始化时，预申请的内存长度（单位为字节），参数 iStep 用于指定当管理器内存不足时，扩充内存数量的步长（一次扩充这么多个字节的内存），可根据实际需求设置。
由 MBMU_Create 创建的对象，不再使用时应调用 MBMU_Destroy 函数将 MBMU 对象销毁，否则会产生内存泄漏。

### MBMU_Destroy - 销毁内存缓冲区管理器
声明：void MBMU_Destroy(MBMU_Object pObject);
销毁由 MBMU_Destroy 函数创建的 MBMU 对象。

### MBMU_Init - 初始化缓冲区管理器
声明：void MBMU_Init(MBMU_Object pObject, unsigned int iAllocLength, unsigned int iStep);
这个函数和 MBMU_Create 功能类似，它在不申请 MBMU 对象内存的情况下，对已存在的 MBMU_Struct 数据进行初始化，将 MBMU_Struct 嵌入到其他数据结构中的情况下，应使用此函数进行数据初始化。
嵌入到其他数据结构的 MBMU_Struct 不再使用时应调用 MBMU_Unit 函数释放对象中的数据，否则会产生内存泄漏。

### MBMU_Unit - 释放缓冲区管理器
声明：void MBMU_Unit(MBMU_Object pObject);
释放 MBMU 对象内的数据，它会将管理器中的数据清零，并释放管理器占用的内存。

### MBMU_Malloc - 分配内存
声明：int MBMU_Malloc(MBMU_Object pObject, unsigned int iCount);
MBMU_Malloc 是 MBMU 的内存分配函数，通常你不需要调用这个函数，因为 MBMU 会自己想办法管理内存，在适当的时候调用它，但如果你已经提前知道将要添加多少数据到 MBMU 中时，可以通过它来预先分配足够大的内存，来提升性能。
MBMU_Malloc 会将 MBMU 管理器的内存申请到能够容纳 iCount 字节的状态，如果当前内存不足这个数量，会对内存进行扩容，如果当前内存超出了这个数量，则会对内存进行裁剪（如果管理器中的数据超过了这个数量，则会对数据进行裁剪）（例如 MBMU 中有 10 字节数据，执行 MBMU_Malloc(obj, 5) 之后，MBMU 只会留下 5 字节数据）。
操作成功返回 TRUE，操作失败返回 FALSE。

### MBMU_Insert - 中间添加数据
声明：int MBMU_Insert(MBMU_Object pObject, unsigned int iPos, void* pData, unsigned int iSize, unsigned int bStrMode);
将 pData 中的 iSize 个字节的数据添加到 iPos 位置。
bStrMode 可以指定字符串模式，可选值为：MBMU_BINARY、MBMU_ANSI、MBMU_UNICODE、MBMU_UTF8、MBMU_UTF32。
当 bStrMode 指定为 MBMU_BINARY 时，iSize 不可以传递为 0，使用字符串模式可以将 iSize 传递为 0，会自动统计 pData 的字符串长度。
如果指定的 iPos 不为原始数据末尾，则 iPos 之后的数据会被覆盖。
操作成功返回 TRUE，操作失败返回 FALSE。

### MBMU_Append - 末尾添加数据
声明：int MBMU_Append(MBMU_Object pObject, void* pData, unsigned int iSize, unsigned int bStrMode);
将 pData 中的 iSize 个字节的数据添加到现有数据的末尾。
bStrMode 参数相关的描述请参考 MBMU_Insert。
操作成功返回 TRUE，操作失败返回 FALSE。

### MBMU_Clear - 清空数据
MBMU_Unit 的别名，为了避免歧义时，可以使用 MBMU_Clear。
