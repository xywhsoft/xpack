## AVLHT64（AVLTree Hash Table 64）模块：

分类：实用性工具类（用于特定功能实现）

AVLHT64 是基于 64位哈希算法 + AVLTree 实现的哈希表，而不是使用传统哈希桶方式实现的。

二叉树具备非常强悍的查询性能，优秀的插入、删除性能，是制作哈希表的优秀选择，搭配 64 位哈希算法，有效减少了数据碰撞的可能性。

通常四种哈希表根据使用需要选择一种即可。

### AVLHT64_Struct [数据结构]
``` c
typedef struct {
	AVLTree_Struct AVLT;
	#ifdef MMU_USE_MP256
		MP256_Object MP;
	#endif
} AVLHT64_Struct, *AVLHT64_Object;
```
AVLHT64_Struct 是 AVLHT64 对象的基本结构体数据，可以通过 AVLHT64_Create 函数创建一个指向 AVLHT64_Struct 结构体的指针（也就是 AVLHT64_Object）。

AVLHT64 必须使用已经初始化过的 AVLHT64_Struct 数据结构（使用 AVLHT64_Create），否则在进行 API 调用时，可能产生无法预知的严重后果。

### AVLHT64_Object [对象指针]
AVLHT64_Object 是 AVLHT64_Struct 数据结构的指针，通过 AVLHT64_Create 创建的 AVLHT64 对象会返回 AVLHT64_Object 对象指针。

### AVLHT64_Create - 创建哈希表
声明：AVLHT64_Object AVLHT64_Create(unsigned int iItemLength);
创建 AVLHT64 对象并初始化数据，创建成功时返回一个 AVLHT64_Object 对象指针，创建失败返回 NULL。
由 AVLHT64_Create 创建的对象，不再使用时应调用 AVLHT64_Destroy 函数将 AVLHT64 对象销毁，否则会产生内存泄漏。

### AVLHT64_Destroy - 销毁哈希表
声明：void AVLHT64_Destroy(AVLHT64_Object objHT);
销毁由 AVLHT64_Create 函数创建的 AVLHT64 对象。

### AVLHT64_Init - 初始化哈希表
声明：void AVLHT64_Init(AVLHT64_Object objHT, unsigned int iItemLength);
这个函数和 AVLHT64_Create 功能类似，它在不申请 AVLHT64 对象内存的情况下，对已存在的 AVLHT64_Struct 数据进行初始化，将 AVLHT64_Struct 嵌入到其他数据结构中的情况下，应使用此函数进行数据初始化。
嵌入到其他数据结构的 AVLHT64_Struct 不再使用时应调用 AVLHT64_Unit 函数释放对象中的数据，否则会产生内存泄漏。

### AVLHT64_Unit - 释放哈希表
声明：void AVLHT64_Unit(AVLHT64_Object objHT);
释放 AVLHT64 对象内的数据，它会将管理器成员数量清零，并释放管理器占用的内存。

### AVLHT64_Set - 设置值
声明：void* AVLHT64_Set(AVLHT64_Object objHT, void* sKey, unsigned int iKeyLen);
设置表内 sKey 元素的值（sKey 的长度为 iKeyLen）。
运行后会返回 sKey 对应的元素结构体指针，可通过这个指针对 sKey 对应的元素进行操作。
如果表内不存在 sKey 对应的值，会创建新值返回。

### AVLHT64_Get - 获取值
声明：void* AVLHT64_Get(AVLHT64_Object objHT, void* sKey, unsigned int iKeyLen);
获取表内 sKey 元素的值（sKey 的长度为 iKeyLen）。
运行后会返回 sKey 对应的元素结构体指针，可通过这个指针对 sKey 对应的元素进行操作。

### AVLHT64_Remove - 删除值
声明：int AVLHT64_Remove(AVLHT64_Object objHT, void* sKey, unsigned int iKeyLen);
删除表内 sKey 元素的值（sKey 的长度为 iKeyLen）。
成功返回 TRUE，失败返回 FLASE（值不存在时）。

### AVLHT64_Exists - 判断值是否存在
声明：int AVLHT64_Exists(AVLHT64_Object objHT, void* sKey, unsigned int iKeyLen);
判断表内 sKey 元素的值（sKey 的长度为 iKeyLen）是否存在。

### AVLHT64_RemoveAll - 删除所有成员
AVLHT64_Unit 的别名，为了避免歧义时，可以使用 AVLHT64_RemoveAll。

### AVLHT64_Clear - 清空管理器
AVLHT64_Unit 的别名，为了避免歧义时，可以使用 AVLHT64_Clear。

### AVLHT64_Count - 获取表内元素数量
声明：unsigned int AVLHT64_Count(AVLHT64_Object objHT);
获取哈希表内元素的数量。

### AVLHT64_Walk - 遍历表元素
声明：void AVLHT64_Walk(AVLHT64_Object objHT, HT64_EachProc procEach, void* pArg);
通过回调函数 recuProc 遍历哈希表所有元素，pArg 会作为 recuProc 的参数传递。
