## Hash32（nmhash32x）模块：

分类：实用性工具类（用于特定功能实现）

nmhash32x 是性能非常优秀的 32 位哈希算法，无论是 Hash 速度，还是碰撞特性都非常好，MMU 选择使用这种算法作为 Hash Table 的实现算法，你也可以单独使用这种算法进行哈希值计算。

nmhash32x 基于 BSD2 协议开源，源代码中已附带开源许可证。

### Hash32_WithSeed - 计算 32 位哈希值
声明：unsigned int Hash32_WithSeed(void* key, size_t len, unsigned int seed);
计算 key 的哈希值，其中 key 的长度为 len。
使用 seed 作为随机种子。

### Hash32 - 计算 32 位哈希值
声明：unsigned int Hash32(void* key, size_t len);
计算 key 的哈希值，其中 key 的长度为 len。

### Hash32Inline - 计算 32 位哈希值
声明：unsigned int Hash32Inline(void* key, size_t len, unsigned int seed);
计算 key 的哈希值，其中 key 的长度为 len。
使用 seed 作为随机种子。
Hash32Inline 为内联函数，会略微提升运行效率，但显著增加程序体积。
