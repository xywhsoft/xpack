# xpkgui Release Manifest

This document defines what `release/x64` is expected to contain for xpkgui
release purposes. It is a manifest and audit guide only; do not delete files
from the shared release directory without an explicit release-cleanup step.

## Expected xpkgui Outputs

- `release/x64/xpkgui.exe`
- `release/x64/xpkgui_shext.dll`

## Staged xpkgui Package

`tools/xpkgui/package_x64.bat` stages a clean package under:

- `tools/xpkgui/obj/package/x64`

The staged package contains:

- `xpkgui.exe`
- `xpkgui_shext.dll`
- `install_x64.bat`
- `uninstall_x64.bat`
- `README.md`
- `PACKAGE_MANIFEST.txt`
- `docs/USER_GUIDE.md`
- `docs/FAQ.md`
- `docs/RELEASE_CHECKLIST.md`

`PACKAGE_MANIFEST.txt` is generated by `write_package_manifest.ps1` and records
relative paths, byte sizes, and SHA-256 hashes for staged package files.
`verify_package_manifest.ps1` validates the recorded sizes and hashes.

## Expected xPack Tools Used By Smoke

- `release/x64/xpkcon.exe`
- `release/x64/xpack.exe`
- `release/x64/xpack.dll`

## Not Release Payload

The following patterns are not xpkgui release payload and should not be shipped
with the xpkgui package:

- `release/x64/debug_*_probe.exe`
- `release/x64/*_probe.txt`
- `release/x64/*_probe.xpk`
- `release/x64/xpack_archive.xpk`
- `release/x64/smoke_inputs/`
- `release/x64/extract_all/`

## Current Policy

- Smoke output for xpkgui is written under `tools/xpkgui/obj/smoke`, not
  `release/x64`.
- `tools/xpkgui/check_release_x64.bat` audits `release/x64` against this
  manifest. Default mode reports warnings; `/strict` fails on unexpected
  payload.
- `tools/xpkgui/write_release_audit_report.ps1` writes a Markdown audit report
  under `tools/xpkgui/obj/release_audit_x64.md`, including Git-tracked status
  for unexpected release directory items.
- `tools/xpkgui/package_x64.bat` creates a clean xpkgui package without
  deleting files from the shared release directory.
- Existing tracked historical files under `release/x64` are not removed by
  xpkgui development tasks.
- A final release cleanup may stage file deletions or packaging changes, but it
  must be done explicitly because this directory is shared with other xPack
  command-line tools.
