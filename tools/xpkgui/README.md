# xpkgui - xPack 压缩包管理工具

一个基于 Win32 SDK 开发的压缩包管理工具，类似 7-zip 的图形界面工具，用于管理 xPack 格式的压缩包。

## 功能特性

- **文件管理**
  - 新建压缩包
  - 打开/关闭压缩包
  - 保存压缩包
  - 添加文件到压缩包
  - 解压单个/全部文件
  - 删除文件
  - 重命名文件

- **压缩功能**
  - 支持多种压缩算法：LZ4、ZSTD、LZMA2
  - 支持多种压缩级别（0-15）
  - 自动计算压缩比

- **工具功能**
  - 验证压缩包完整性
  - 重建压缩包以优化存储
  - 查看压缩包属性

- **界面特性**
  - 详细信息视图显示文件列表
  - 状态栏显示统计信息
  - 支持双击解压文件

## 编译方法

### 前提条件
- 已安装 TCC 编译器（并添加到环境变量）
- 已有 xPack 源代码

### 编译步骤

#### 64位版本
```bash
cd D:\git\xPack\tools\xpkgui
build_x64.bat
```

#### 32位版本
```bash
cd D:\git\xPack\tools\xpkgui
build_x86.bat
```

编译成功后会在当前目录生成 `xpkgui.exe`。

## 使用说明

### 基本操作

1. **新建压缩包**
   - 点击菜单 `文件` -> `新建`
   - 选择保存位置和文件名
   - 新建的压缩包默认为 Win32 模式

2. **打开压缩包**
   - 点击菜单 `文件` -> `打开`
   - 选择要打开的 `.xpk` 文件

3. **添加文件**
   - 点击菜单 `文件` -> `添加文件`
   - 选择要添加的文件（支持多选）
   - 文件将以默认压缩级别（7，ZSTD greedy）压缩

4. **解压文件**
   - 单击选中要解压的文件
   - 点击菜单 `文件` -> `解压`
   - 或者双击文件进行快速解压
   - 选择解压目标目录

5. **删除文件**
   - 选中要删除的文件
   - 点击菜单 `文件` -> `删除`

6. **重命名文件**
   - 选中要重命名的文件
   - 点击菜单 `文件` -> `重命名`
   - 输入新的文件名

### 工具功能

- **验证压缩包**
  - 点击菜单 `工具` -> `验证`
  - 检查压缩包中所有文件的完整性

- **全部解压**
  - 点击菜单 `工具` -> `全部解压`
  - 将压缩包中所有文件解压到指定目录

- **查看属性**
  - 点击菜单 `文件` -> `属性`
  - 查看压缩包的详细信息（类型、文件数、大小、压缩率等）

### 刷新视图

- 点击菜单 `查看` -> `刷新` 或按 `F5` 键刷新文件列表

## 支持的压缩算法

| 级别 | 算法 | 描述 |
|------|------|------|
| 0 | 无压缩 | 不进行压缩 |
| 1-2 | LZ4 | 快速压缩 |
| 3-4 | LZ4-HC | 高质量 LZ4 压缩 |
| 5-13 | ZSTD | ZSTD 压缩，级别越高压缩比越好 |
| 14-15 | LZMA2 | LZMA2 高压缩比 |

## 支持的包模式

- **Win32 模式**：路径访问，不区分大小写（推荐 Windows 使用）
- **Linux 模式**：路径访问，区分大小写（推荐 Linux 使用）
- **Index 模式**：整数索引访问
- **Core 模式**：顺序位置访问

当前版本新建压缩包默认使用 Win32 模式。

## 依赖

- xrt 运行时库
- xPack 压缩库
- lz4 压缩算法
- lzma 压缩算法
- zstd 压缩算法
- Win32 API

所有依赖都已包含在编译脚本中，无需额外安装。

## 注意事项

1. 当前版本仅支持 Win32 模式和 Linux 模式的路径操作
2. Core 模式和 Index 模式仅支持查看和基础操作
3. 解压时如目标文件已存在会自动覆盖
4. 大文件操作时重建功能可能需要较长时间
