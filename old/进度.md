# xPack Ver7 开发进度

## 项目概述

xPack Ver7 - 轻量级文件压缩包库，支持分卷、多种压缩算法、哈希验证。

## 编译命令

```bash

gcc -g -O0 -DZ7_ST -I. -Ilib/xrt -Ilib/lz4 -Ilib/zstd -Ilib/lzma \
    test/new_core.c xpack.c lib/lz4/lz4.c lib/lz4/lz4hc.c \
    lib/zstd/zstd.c lib/lzma/*.c -o test/new_core_gcc.exe \
    -lws2_32 -liphlpapi

# TCC
tcc -g -DZ7_ST -DZSTD_NO_INTRINSICS -I. -Ilib/xrt -Ilib/lz4 -Ilib/zstd -Ilib/lzma \
    test/new_core.c xpack.c lib/lz4/lz4.c lib/lz4/lz4hc.c \
    lib/zstd/zstd.c lib/lzma/*.c -o test/new_core_tcc.exe \
    -lws2_32 -liphlpapi
```

## 关键设计

### 文件布局
```
[xpkHead 68B] [Data Blocks] [Meta (compressed)] [LDB (compressed)]
     0x00         ↑dataOffset
```

### LDB 段格式
```
LDB = 用户自定义元数据（压缩后存储）
存储信息：
- ldbRawSize (xpkHead.ldbRawSize)
- ldbCompSize (xpkHead.ldbCompSize)
- ldbHash (xpkHead.ldbHash)
- ldbComp (xpkHead.ldbComp)
```

### 数据结构
- `xpkHead` (68 bytes) - 包头（含 ldbRawSize）
- `xpkFileInfo` (32 bytes) - Core 模式文件信息
- `xpkMetaHead` (16 bytes) - Meta 段头

### 分卷命名
- 主卷: `basename.xpk`
- 分卷: `basename.001.xpk`, `basename.002.xpk`, ...
